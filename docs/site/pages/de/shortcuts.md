## Chat-Befehle für Zuschauer

Mit dem Standard-Präfix `!hb` ([Begleiter → Befehle](companion.md#commands)):

| Befehl | Auch | Was passiert |
|---|---|---|
| `!hb frage <Frage>` | `!hb ask`, `!hb q` oder einfach `!hb <Frage>` | Der Bot antwortet – mit Websuche, wenn die Frage aktuelle Fakten braucht. |
| `!hb fakt` | `!hb fact` | Ein Fun Fact zum aktuellen Spiel. |
| `!hb witz` | `!hb joke` | Ein Witz, der zum Stream passt. |
| `!hb hilfe` | `!hb`, `!hb info`, `!hb about`, `!hb help` | Eine kurze Vorstellung und die Liste der verfügbaren Befehle. |

Zuschauer können den Bot auch einfach mit seinem **Namen** (oder einem Trigger-Wort) in einer Nachricht ansprechen oder auf eine seiner Nachrichten **antworten**.

## App

| Tasten | Aktion |
|---|---|
| <kbd>Strg</kbd> + <kbd>K</kbd> | Schnellsuche: zu jeder Seite, Einstellung, jedem Profil oder jeder Aktion springen. |
| <kbd>Strg</kbd> + <kbd>+</kbd> / <kbd>−</kbd> | Oberfläche größer / kleiner (der Chat behält seine eigene Größe). |
| <kbd>Strg</kbd> + Mausrad | Größe der Oberfläche – oder des Chats, wenn der Mauszeiger über dem Chat ist. |
| <kbd>Strg</kbd> + <kbd>0</kbd> | Größe der Oberfläche zurücksetzen. |
| <kbd>Esc</kbd> | Einen Dialog oder einen angehefteten Tooltip schließen. |

## Chat-Eingabe

| Tasten | Aktion |
|---|---|
| <kbd>:</kbd> am Wortanfang | Vorschläge für Emotes und Emojis (`:7`, `:b`, `:f`, `:t`, `:e` für einen Anbieter). |
| <kbd>@</kbd> | Vorschläge von Leuten im Chat. |
| <kbd>Tab</kbd> | Das aktuelle Wort ergänzen oder den gewählten Vorschlag einfügen. |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Einen Vorschlag wählen – oder in einem leeren Feld die letzte Nachricht zurückholen. |
| <kbd>Enter</kbd> | Vorschlag einfügen oder senden. |
| Rechtsklick auf ein Emote (Auswahl) | Als Favorit anheften / Favorit entfernen. |

## Steam-Overlay

| Tasten | Aktion |
|---|---|
| <kbd>Umschalt</kbd> + <kbd>Tab</kbd> | Das Steam-Overlay öffnen (mit dem angehefteten Chat-Fenster und, falls aktiviert, seiner Chat-Eingabe). |

## Diese Dokumentation

| Tasten | Aktion |
|---|---|
| <kbd>Strg</kbd> + <kbd>K</kbd> oder <kbd>/</kbd> | Die Doku durchsuchen. |
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>Enter</kbd> | Ein Suchergebnis wählen und öffnen. |

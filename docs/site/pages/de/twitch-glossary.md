Neu auf Twitch? Diese Begriffe begegnen dir in HighBazar und auf Twitch selbst. Dieselben Erklärungen zeigt die App, wenn du auf ein kleines ⓘ zeigst.

## Personen und Rollen

| Begriff | Bedeutung |
|---|---|
| **Streamer / Broadcaster** | Du – die Person, der der Kanal gehört. |
| **Zuschauer / Chatter** | Jemand, der zuschaut; ein Chatter schreibt auch im Chat. |
| **Lurker** | Jemand, der zuschaut, ohne zu schreiben. Die meisten Zuschauer sind Lurker – ein guter Bot lädt sie zum Chatten ein. |
| **Follower** | Jemand, der auf *Folgen* geklickt hat, um benachrichtigt zu werden, wenn du live gehst. Kostenlos. |
| **Abonnent (Sub)** | Jemand, der dich monatlich mit Geld unterstützt (Prime Gaming gibt einen kostenlosen Sub pro Monat). Subs bekommen ein Abzeichen und die Emotes deines Kanals. Stufe 1, 2 und 3 kosten jeweils mehr. |
| **Moderator (Mod)** | Ein vertrauter Zuschauer, der in deinem Chat Nachrichten löschen, Timeouts geben und bannen kann. Gib die Rolle nur Leuten, die du gut kennst (`/mod name`). |
| **VIP** | Ein vertrauter Zuschauer mit Diamant-Abzeichen, der den langsamen Modus und den Nur-Follower-Modus umgehen darf – ein Dankeschön ohne Moderationsrechte. |
| **Editor** | Jemand, dem du erlaubt hast, Titel und Kategorie zu ändern oder Werbung für dich zu starten. |
| **Affiliate / Partner** | Twitchs Stufen zum Geldverdienen. Affiliates und Partner bekommen Subs, Bits, Kanalpunkte, Umfragen, Vorhersagen und Werbung. Partner bekommen mehr, z. B. eine Stream-Verzögerung. |

## Unterstützung und Events

| Begriff | Bedeutung |
|---|---|
| **Bits / Cheer** | Twitchs eigene Währung. Ein Cheer ist ein Trinkgeld mit Bits in einer Chatnachricht; 100 Bits sind für dich etwa ein US-Dollar. |
| **Sub-Geschenk** | Jemand kauft ein Abo für einen anderen Zuschauer oder für die Community. |
| **Resub** | Ein Abonnent teilt mit, wie lange er schon abonniert ist. |
| **Raid** | Ein anderer Streamer beendet seinen Stream und schickt seine Zuschauer zu dir. Bedank dich beim Raider – ein Shoutout ist üblich. |
| **Shoutout** | Twitchs offizieller Shoutout: eine Karte in deinem Chat, die einen anderen Streamer mit Folgen-Knopf empfiehlt. Nur live, höchstens alle 2 Minuten. |
| **Hype-Train** | Abonnieren oder cheeren viele Leute in kurzer Zeit, arbeitet der Chat gemeinsam auf höhere Stufen hin und schaltet Belohnungs-Emotes frei. |
| **Zuschauer-Serie** | Jemand hat mehrere deiner Streams hintereinander geschaut – Twitch lässt ihn das im Chat teilen. |
| **Kanalpunkte** | Kostenlose, virtuelle Punkte, die Zuschauer durchs Zuschauen und Chatten sammeln und für Belohnungen ausgeben, die du anlegst („Trink was!“, „Frag den Bot“). Nur für Affiliates und Partner. |
| **Umfrage** | Zuschauer stimmen in einem Kasten über dem Chat zwischen bis zu 5 Optionen ab. |
| **Vorhersage** | Zuschauer setzen Kanalpunkte auf einen Ausgang; die Gewinner teilen sich die Punkte der Verlierer. |

## Chat

| Begriff | Bedeutung |
|---|---|
| **Emote** | Ein kleines Bild im Chat, geschrieben als Wort (`Kappa`, `catJAM`). Twitch hat eigene; deine Abonnenten bekommen die Emotes deines Kanals. |
| **BTTV, FFZ, 7TV** | BetterTTV, FrankerFaceZ und 7TV – kostenlose Browser-Erweiterungen, die weitere Emotes hinzufügen. Zuschauer sehen sie nur als Bild, wenn sie die Erweiterung nutzen. |
| **Zero-Width-Emote** | Ein Emote, das über das vorherige gelegt wird, z. B. ein Hut oder Regen (7TV, BTTV). |
| **Erst-Chatter** | Jemand, der zum ersten Mal in deinem Chat schreibt – Twitch markiert ihn, und HighBazar kann ihn begrüßen. |
| **Antwort** | Auf Twitch kannst du auf eine bestimmte Nachricht antworten (darauf zeigen → Antworten). |
| **Ankündigung** | Eine hervorgehobene Nachricht mit farbigem Balken, für Wichtiges. |
| **Angepinnte Nachricht** | Eine Nachricht, die oben im Chat angeheftet ist, damit alle sie sehen. |
| **Shared Chat** {#shared-chat} | Streamen mehrere Leute zusammen, können sie ihre Chats zusammenlegen; Nachrichten aus den Partner-Kanälen erscheinen dann auch bei dir. HighBazar zeigt sie, moderiert und begrüßt sie aber nicht. |
| **Backseating** | Dem Streamer ungefragt sagen, wie er spielen soll – viele Kanäle haben eine Regel dagegen. |
| **Spoiler** | Wendungen der Story verraten – eine weitere häufige Chat-Regel. |

## Chat-Modi und Sicherheit

| Begriff | Bedeutung |
|---|---|
| **Nur Emotes** | Nur Nachrichten aus Emotes sind erlaubt. |
| **Nur Follower** | Nur wer mindestens eine bestimmte Zeit folgt, kann schreiben – sehr wirksam gegen Bot- und Hate-Raids. |
| **Nur Abonnenten** | Nur Abonnenten können schreiben. |
| **Langsamer Modus** | Jede Person kann nur alle paar Sekunden eine Nachricht senden. |
| **Einzigartiger Chat (R9K)** | Eine Nachricht, die eine kürzliche wiederholt, wird blockiert. |
| **Chat-Verzögerung** | Nachrichten normaler Zuschauer erscheinen ein paar Sekunden später, damit Mods eingreifen können. |
| **Timeout** | Schaltet jemanden eine Weile stumm – zuschauen kann er weiter. |
| **Bann** | Entfernt jemanden aus deinem Chat, bis du ihn entbannst. Er kann eine *Entbann-Anfrage* stellen. |
| **Verwarnung** | Eine Warnung, die die Person bestätigen muss, bevor sie weiterchatten kann. |
| **AutoMod** | Twitchs eigener Filter: Er hält riskante Nachrichten zurück, bis ein Moderator sie erlaubt oder ablehnt. Stufen 0–4. |
| **Gesperrte Begriffe** | Wörter, die Twitch (oder HighBazar) in deinem Chat immer blockiert. |
| **Schild-Modus** | Ein Notfallknopf, der deine strengsten Chat-Einstellungen auf einmal einschaltet. |
| **Hate-Raid** | Viele (oft gefälschte) Accounts spammen gleichzeitig Hass. Schild-Modus und Nur-Follower-Modus helfen. |
| **Verdächtiger Nutzer** | Ein Account, den du markiert hast: *Überwachen* hebt seine Nachrichten für deine Mods hervor, *Einschränken* blendet sie für alle anderen aus. |

## Stream

| Begriff | Bedeutung |
|---|---|
| **Kategorie** | Das Spiel oder Thema deines Streams (z. B. *Just Chatting*). Zuschauer stöbern auf Twitch nach Kategorien. |
| **Tags** | Stichwörter, nach denen Zuschauer im Verzeichnis filtern können. |
| **Inhaltskennzeichnungen** | Warnungen vor Inhalten für Erwachsene wie Gewalt, Drogen, Glücksspiel oder sexuellen Themen. |
| **Markeninhalte** | Bezahlte Werbung oder Sponsoring in deinem Stream – Twitch zeigt den Zuschauern einen Hinweis. |
| **VOD** | Die Aufzeichnung deines vergangenen Streams. |
| **Clip** | Ein kurzes Video eines Moments aus deinem Stream, das Zuschauer teilen können. |
| **Stream-Marker** | Ein Lesezeichen in deinem VOD, um einen Moment wiederzufinden. |
| **Stream-Verzögerung** | Verzögert deinen Stream für die Zuschauer, z. B. gegen Stream-Sniping. Nur für Partner. |
| **Stream-Sniping** | Gegner in einem kompetitiven Spiel schauen deinen Stream, um dich zu finden. |
| **Pre-Roll / Mid-Roll** | Werbung vor dem Stream-Start für neue Zuschauer / Werbung während deines Streams. Nach einem Mid-Roll lässt Twitch die Pre-Rolls eine Weile weg. |
| **Werbe-Manager** | Twitchs Einstellungen für Werbedichte und automatische Werbung. |
| **Zeitplan** | Dein Stream-Zeitplan auf deiner Kanalseite – Zuschauer können sich erinnern lassen. |
| **Präfix** | Die Kennzeichnung von HighBazar (z. B. `[HighBazar]`) vor Bot-Nachrichten, die über deinen Account gesendet werden, damit Zuschauer wissen, dass sie vom Bot kommen. |

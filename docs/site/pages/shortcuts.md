## Chat commands for viewers

With the default prefix `!hb` ([Companion → Commands](companion.md#commands)):

| Command | Also | What happens |
|---|---|---|
| `!hb ask <question>` | `!hb frage`, `!hb q`, or just `!hb <question>` | The bot answers – with a web search if the question needs current facts. |
| `!hb fact` | `!hb fakt` | A fun fact about the current game. |
| `!hb joke` | `!hb witz` | A joke that fits the stream. |
| `!hb about` | `!hb`, `!hb help`, `!hb hilfe`, `!hb info` | A short introduction and the list of available commands. |

Viewers can also simply **write the bot's name** (or a trigger word) in a message, or **reply** to one of its messages.

## App

| Keys | Action |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>K</kbd> | Quick search: jump to any page, setting, profile or action. |
| <kbd>Ctrl</kbd> + <kbd>+</kbd> / <kbd>−</kbd> | Interface larger / smaller (the chat keeps its own size). |
| <kbd>Ctrl</kbd> + mouse wheel | Interface size – or chat size when the pointer is over the chat. |
| <kbd>Ctrl</kbd> + <kbd>0</kbd> | Reset the interface size. |
| <kbd>Esc</kbd> | Close a dialog or a pinned tooltip. |

## Chat input

| Keys | Action |
|---|---|
| <kbd>:</kbd> at the start of a word | Emote and emoji suggestions (`:7`, `:b`, `:f`, `:t`, `:e` for one provider). |
| <kbd>@</kbd> | Suggestions of people in chat. |
| <kbd>Tab</kbd> | Complete the current word, or insert the selected suggestion. |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Choose a suggestion – or, in an empty field, bring back your last message. |
| <kbd>Enter</kbd> | Insert the suggestion, or send. |
| Right-click an emote (picker) | Pin as favorite / remove favorite. |

## Steam overlay

| Keys | Action |
|---|---|
| <kbd>Shift</kbd> + <kbd>Tab</kbd> | Open the Steam overlay (with the pinned chat window and, if enabled, its chat input). |
